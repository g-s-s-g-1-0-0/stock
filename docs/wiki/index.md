# 투자 전략 멘토링 기본 맥락

최종 갱신: 2026-09-20  
목적: 향후 투자 상황·재진입·보유·청산 질문에 일관된 기준으로 답하기 위한 진입 문서다. 시세와 뉴스는 이 문서에 적힌 값을 재사용하지 말고 질문 시점에 다시 확인한다.

## 1. 사용자 상황

- 2026년 7월~8월 초 SK하이닉스, SOXL, Astera Labs(ALAB), Credo(CRDO) 등 반도체·AI 인프라 종목에 집중했다가 약 50% 손실을 경험했다.
- 이후 금리와 경기 위험을 우려해 손절하고 현금화했다.
- 현재 핵심 고민은 반도체 장기 성장 전망은 유지하면서도 재진입 시점을 어떻게 정할지다.
- 빠른 원금 회복보다 추가 대규모 손실 방지와 반복 가능한 의사결정을 우선한다. 50% 손실은 회복에 100% 수익이 필요하므로 복구 목적의 몰빵·추격매수를 경계한다.
- 답변은 멘토링 방식으로 하되 최대한 간결하고 결론 중심으로 작성한다.

## 2. 전략 1~6 기준

기계 판독 기준은 `output/trend_strategy/refine_six/ADOPTED_RULES.json`, 사람이 읽는 최종 정의는 `output/trend_strategy/refine_six/FINAL_STRATEGIES.md`다.

우선순위는 **1 > 2 > 3 > 4 > 5 > 6**이다.

1. 공포·과매도 반등
2. 회복장 이평선 눌림
3. 상승 추세 내 과매도
4. MA200 아래 MACD 반등
5. 돌파 후 눌림·지지 확인
6. 하락 추세 이탈 시도

공통 원칙:

- 장 마감 신호를 확인하고 다음 거래일 시가에 진입한다.
- 종목당 기본 최대 비중은 순자산 10%이며 최대 10개 종목, 물타기·중복 포지션·보유 중 전략 변경은 하지 않는다.
- 같은 종목·같은 날에는 번호가 가장 낮은 전략만 사용한다.
- 전략 5·6은 기존 전략을 대체하거나 조기 진입을 합리화하는 장치가 아니다. 정확한 조건이 충족될 때만 사용한다.
- 과거 손실을 고려한 개인 위험 오버레이로 반도체군 총비중 20%를 우선 권고한다. 이는 기존 백테스트 가정에 없는 보수적 제한임을 명시한다.
- SOXL은 일일 수익률 3배를 목표로 하는 레버리지 ETF이므로 장기 반도체 성장 투자의 코어로 취급하지 않는다. 사용하더라도 최대 5%의 전술 포지션으로 제한하는 방향을 우선 검토한다.

## 3. 판단 우선순위

향후 질문에는 아래 순서로 답한다.

1. **현재 포지션과 손실 허용액**: 현금·보유 종목·평단·비중·전략 번호를 확인한다.
2. **시장 진입 허용 여부**: QQQ MA200 이격도(Q), 회복장 여부, VIX, QQQ RSI·MACD, 시장 이벤트를 확인한다.
3. **전략 완전 충족 여부**: 일부 조건 충족이나 차트 인상으로 신호를 앞당기지 않는다.
4. **종목 고유 위험**: 실적 일정, 밸류에이션, 고객 집중, 제품 램프, 환율을 확인한다.
5. **상관관계와 총위험**: 여러 반도체 종목을 서로 다른 분산 자산처럼 계산하지 않는다.
6. **실행안**: 지금 할 행동, 진입 크기, 무효화·손절 조건, 다음 확인 일정을 제시한다.

## 4. 분석 시 반드시 새로 확인할 자료

- `web/public/api/technical.json`: 갱신 시각, QQQ/VIX, 각 종목의 최종 판단과 전략 조건
- `web/public/api/market-events.json`: 공식 일정 검증 상태와 실패 여부
- `output/trend_strategy/live_comparison/COMPARISON.md`: 전략별 강건성 및 한계
- 연준·BLS·BEA·EIA 등 공식 최신 자료
- 대상 기업 IR·실적 발표와 공식 가이던스
- 질문일 기준 가격과 차트. 저장 데이터가 오래됐으면 오래됐다고 밝히고 최신 자료로 교차 확인

뉴스는 미래를 확정하는 신호가 아니라 전략 신호의 배경과 이벤트 위험을 설명하는 보조 근거로 사용한다.

## 6. 기본 답변 형식

향후 멘토링 답변은 특별한 요청이 없으면 다음 다섯 항목만 짧게 제시한다.

1. **결론**: 매수 / 대기 / 축소 / 청산
2. **핵심 근거**: 최대 세 가지
3. **실행 비중**: 계좌 기준 수치
4. **무효화 조건**: 손절 또는 판단 변경 기준
5. **다음 확인일**: 거시지표·실적·전략 재평가 시점

불확실한 전망을 단정하지 않고, 사용자의 전제가 최신 사실과 다르면 직접 정정한다. 전략 규칙을 임의로 바꾸는 제안은 기존 백테스트와 다른 위험 오버레이라고 구분해서 표시한다.
